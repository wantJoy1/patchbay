# patchbay

## 注意

このプログラムは実験的なものです。

## 目標

既存の UI では、次の対応付けが不完全である。

- **入力から処理系へ**：入力を、それを解釈できる処理系（シェル、言語の処理系、CLI、AI エージェントなど）に渡す。ブラウザは手元の処理系に渡せない。
- **出力から描画方式へ**：出力を、その形式に合う方式で描画し、描画から元の出力へ戻れる。ターミナルは描画方式が乏しい。

これらの問題が解消された UI を目指す。

## 小目標

以下の形態をサポートすることを目指す。

- (Claude Code のような) AI 向けのクライアント UI 
- ターミナル
